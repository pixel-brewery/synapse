Try Synapse from a checkout

Use Node.js 24.15 or newer. The simulation processes a sample meeting transcript and returns validated JSON without an assistant account. 

git clone https://github.com/pixel-brewery/synapse.git
cd synapse
corepack enable
yarn install --immutable
yarn nx run meeting-notes:build --parallel=1
yarn workspace @pixel-brewery/synapse-meeting-notes-example start --simulate

To integrate Synapse in your own app, configure the GitHub npm registry and install the packages you need.
