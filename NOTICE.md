# Provenance

Synapse is distributed under MIT. The native Codex, Claude Code and OpenCode adapters, bounded progress handling and generic routing incorporate technical behavior extracted from Symphony (MIT). The affected package licenses preserve Symphony's original copyright notice. Business prompts, domain workflows, SQLite persistence and application UI remain in Symphony.

Archipel's architecture skill foundations are retained under the canonical Synapse architecture skill. Its origin manifest records the reference revision and content hashes; local adaptations live in separate project references. TypeDoc plus typedoc-plugin-markdown follows Archipel's API-documentation approach.

T3 Code, Coding Agent Runner, Agents Wire and Unigent informed architectural decisions. They are not Synapse runtime dependencies, and no implementation from them is incorporated. The ACP adapter depends on the official ACP TypeScript SDK through its own provider package.

Transport fixtures use synthetic, sanitized messages with provenance beside their owners. They do not claim to be private-account recordings or proof of live account integration. External CLI installation, native subscription permissions and release publication remain explicit host or owner actions.
