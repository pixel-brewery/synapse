# Interface: ICodexTokenUsage

Native account usage statistics, distinct from per-turn token usage.

## Properties

### currentStreakDays?

> `readonly` `optional` **currentStreakDays?**: `number`

Native current activity streak in calendar days.

***

### lifetimeTokens?

> `readonly` `optional` **lifetimeTokens?**: `number`

Native lifetime token total when reported.

***

### peakDailyTokens?

> `readonly` `optional` **peakDailyTokens?**: `number`

Native highest daily token total when reported.
